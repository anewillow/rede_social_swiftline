# Swiftline

O projeto está organizado em três pastas:

| Pasta | Conteúdo |
| --- | --- |
| [sistema](./sistema/) | Código da aplicação, dependências, migrações e testes. |
| [trabalho1_manutencao_corretiva](./trabalho1_manutencao_corretiva/) | Relatórios, apresentação e evidências da manutenção corretiva. |
| [trabalho2_manutencao_preventiva](./trabalho2_manutencao_preventiva/) | Espaço reservado para o trabalho de manutenção preventiva. |

## Executar o sistema

Os comandos npm devem ser executados dentro de `sistema`:

```bash
cd sistema
npm install
npm run dev
```

Consulte o [guia de configuração do sistema](./trabalho1_manutencao_corretiva/docs/apresentacao-sistema.md) para preparar o MySQL e o arquivo `sistema/.env`.

A pasta `.github` e o arquivo `.gitignore` permanecem na raiz para configurar o repositório e seus modelos de issues.
