# Issue 05 — Mensagem de erro ao publicar

## Heurística relacionada

**9 — Reconhecimento e recuperação de erros**

## Problema

Quando uma publicação falha, o aviso **Publicando...** desaparece, mas o sistema
não explica o que aconteceu. A pessoa não sabe se deve tentar novamente.

## Mudança

Mostrar uma mensagem clara quando a publicação não for concluída. O Post será mantido e haverá a opção **Tentar novamente**.

## Critérios de conclusão

- [x] Informar que a publicação não foi concluída.
- [x] Manter o texto digitado.
- [x] Mostrar a opção **Tentar novamente**.
- [x] Bloquear novos cliques enquanto a tentativa estiver em andamento.
