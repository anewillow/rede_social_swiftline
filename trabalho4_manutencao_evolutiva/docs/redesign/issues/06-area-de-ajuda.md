# Issue 06 — Área de ajuda

## Heurística relacionada

**10 — Ajuda e documentação**

## Problema

O Swiftline não possui uma área que explique como usar suas principais funções.
Quem tiver uma dúvida precisa descobrir sozinho o que fazer.

## Mudança

Adicionar a opção **Ajuda** ao menu. A página apresentará orientações curtas sobre
como publicar, enviar mensagens, salvar publicações e alterar o perfil.

## Critérios de conclusão

- [x] A opção **Ajuda** aparece no menu.
- [x] A página possui pesquisa de assuntos.
- [x] Cada orientação explica uma tarefa específica.
- [x] Os botões levam diretamente para a função explicada.
- [x] A página segue o visual do Swiftline.
