# Issue 09 — Modo de alto contraste

[Abrir a Issue 09 no GitHub](https://github.com/anewillow/rede_social_swiftline/issues/19)

## Tipo

Manutenção evolutiva — acessibilidade.

## Problema

Alguns textos, ícones e bordas usavam cores claras sobre fundos também claros.
Isso podia dificultar a leitura para pessoas com baixa visão ou dificuldade para
diferenciar cores.

## Melhoria

Adicionar nas configurações um modo de alto contraste que possa ser ativado ou
desativado pelo usuário.

## Justificativa

O modo de alto contraste deixa os textos, botões e limites dos elementos mais
visíveis. A mudança também facilita a navegação pelo teclado.

## Critérios de conclusão

- [x] A opção **Alto contraste** aparece nas configurações.
- [x] O modo pode ser ativado e desativado.
- [x] Textos, fundos, bordas e botões ficam mais fáceis de distinguir.
- [x] A mudança aparece nas principais telas do sistema.
- [x] O foco fica visível durante a navegação com a tecla `Tab`.
- [x] A preferência continua ativa após atualizar a página.
