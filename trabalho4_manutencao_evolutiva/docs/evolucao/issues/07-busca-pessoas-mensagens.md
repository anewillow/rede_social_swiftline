# Issue 07 — Busca de pessoas nas mensagens

[Abrir a Issue 07 no GitHub](https://github.com/anewillow/rede_social_swiftline/issues/17)

## Tipo

Manutenção evolutiva — nova funcionalidade.

## Problema

A tela de mensagens não possuía uma busca própria. Quando a lista tinha muitas
pessoas, era necessário procurar cada nome manualmente.

## Funcionalidade

Adicionar uma busca por nome na lista de conversas. A pesquisa deve consultar os
usuários cadastrados e permitir abrir uma conversa pelo resultado.

## Justificativa

A busca torna a tela de mensagens mais prática e permite encontrar pessoas que
não aparecem imediatamente na lista inicial.

## Critérios de conclusão

- [x] O campo de busca aparece na tela de mensagens.
- [x] A pesquisa aceita parte do nome.
- [x] A busca consulta os usuários cadastrados.
- [x] Um resultado pode ser selecionado para abrir a conversa.
- [x] A tela informa quando nenhuma pessoa é encontrada.
- [x] O campo possui uma opção para limpar a pesquisa.
