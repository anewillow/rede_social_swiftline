# Issue 08 — Enquetes nas publicações

[Abrir a Issue 08 no GitHub](https://github.com/anewillow/rede_social_swiftline/issues/18)

## Tipo

Manutenção evolutiva — nova funcionalidade.

## Problema

O botão de enquete aparecia na área de publicação, mas não funcionava. O sistema
permitia publicar somente texto e imagem.

## Funcionalidade

Permitir a criação de enquetes no feed, com pergunta, opções de resposta, votação
e gráfico dos resultados.

## Justificativa

As enquetes permitem fazer perguntas e acompanhar a opinião dos usuários sem
sair do feed.

## Critérios de conclusão

- [x] O botão de enquete abre os campos de criação.
- [x] A enquete aceita de duas a quatro opções.
- [x] Opções vazias ou repetidas são bloqueadas.
- [x] Cada usuário pode votar apenas uma vez.
- [x] O voto precisa ser confirmado antes do envio.
- [x] O gráfico mostra a porcentagem e a quantidade de votos.
- [x] Quem criou a enquete pode editar ou excluir.
